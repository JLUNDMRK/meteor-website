Add your first library

Connect a movie collection on your local network via SMB, WebDAV, or DLNA.

Contents

  1. Steps
  2. Find automatically
  3. Browse and select
  4. Troubleshooting

Steps

  1. Connect your device to the same local network as your media server or NAS.
  2. Open Meteor.
  3. Add a movie collection location (see How-to for DLNA vs WebDAV vs SMB).
  4. Select the folder containing your movies.
  5. Start indexing.

Your movie files stay on your media server or NAS. Meteor only reads them to build a local index on the device so you can browse and search the library. Meteor does not run a server for your collection, and you do not need to install a web server on the NAS.

Find automatically

Meteor can search the local network for SMB shares and DLNA media servers, and you can add WebDAV manually. For a plain-language comparison and setup outlines (Synology + Windows), see How to connect your movies.

Discovery depends on your router, firewall, and how the media server is shared. Not every network or NAS configuration will work the same way.

Browse and select

Browse the folders exposed by a discovered server and choose the folder Meteor should index.

Prefer a folder that primarily contains movie files (or clearly named movie folders). Cleaner folder names usually lead to better identification.

Having trouble?

If Meteor cannot find your server, or indexing does not start as expected, see the Help page for common network and sharing checks.
