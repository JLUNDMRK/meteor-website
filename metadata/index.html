Metadata & Attribution

How Meteor identifies titles and shows posters and details.

Privacy Policy Terms of Use Contact

Current sources

Meteor currently uses the OMDb API to identify movies and retrieve titles and descriptive metadata, and may use Wikimedia / Wikidata-related sources for artwork and related lookup data when configured. Metadata is cached on the device. Meteor does not operate a central catalog that redistributes your library’s metadata to other users.

Metadata can be incomplete, outdated, or incorrect. Provider availability and terms can change. Third-party names, artwork, and data remain subject to their respective owners and licences.

Future versions of Meteor may include additional data sources. Attribution on this page will be updated when that happens.

OMDb

This product uses the OMDb API (CC BY-NC 4.0; personal / non-commercial).

Meteor relies on the OMDb API for accurate titles and metadata. Users are encouraged to support OMDb — for example by contributing to the project or by using their own API key where that option is offered.

Homepage: omdbapi.com

Wikimedia

Film artwork and related descriptive data may come from Wikimedia Commons, Wikidata, or other Wikimedia-related sources when Meteor is configured to use them. Content remains subject to the licences and attribution requirements of those projects.

Wikimedia: wikimedia.org · Wikidata: wikidata.org

Incorrect matches

Automatic identification is a best-effort guess from filenames and folder names. If the wrong title is chosen, pick the correct movie with a manual search in the app. If nothing suitable appears, the title may simply not be in the metadata source’s database — Meteor does not maintain that catalog, and there is no need to report individual mismatches.

Where age ratings or similar labels appear in metadata, Meteor only displays what your library or these sources provide. See the Terms of Use for responsibility wording.
