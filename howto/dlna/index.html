Set up DLNA

Recommended first option for home use. Usually no username or password in Meteor. Your phone, tablet, or TV and the PC/NAS must be on the same Wi‑Fi / home network.

← Media access SMB WebDAV
DLNA shares what the media server chooses to expose. Folder layout, extras, and sidecar subtitle files are not guaranteed — that depends on the server, not on Meteor alone.

In Meteor

  1. Connect to the same network as your PC or NAS.
  2. Add a library and look for DLNA / media server discovery.
  3. Pick the server and the movie folder (or collection) Meteor should index.

Enable a media server

Open the section that matches your device. Menu names vary slightly by software version.

Windows PC

Windows can share libraries with DLNA-style media streaming. The controls live in the classic Control Panel.

  1. Put your movie files in a Videos library folder (or add that folder to the Videos library).
  2. Open Control Panel → Network and Sharing Center → Media streaming options.
  3. Choose Turn on media streaming. Give the library a clear name and allow devices on your private network.
  4. If the option is missing, enable Windows Media Player under optional / Windows features (N editions may need the Media Feature Pack).
  5. Allow the media sharing service through Windows Firewall on private networks if prompted.
  6. Keep the PC awake (or able to wake) while you watch.

Official context: Microsoft Windows support (search “media streaming” for your Windows version).

Synology
  1. In Package Center, install Media Server.
  2. Open Media Server and share the folders that contain your movies (defaults often include a video shared folder).
  3. Confirm newly detected DLNA devices are allowed if you use access restrictions.
  4. On the same Wi‑Fi as the NAS, discover the server in Meteor.

Vendor help: Synology Knowledge Center (search “Media Server” / DLNA for your DSM version).

QNAP
  1. Enable multimedia services if required (often under Control Panel → Applications → Multimedia Console).
  2. Go to Control Panel → Applications → DLNA Media Server and enable it.
  3. Confirm the folders / user permissions that define which videos appear.
  4. Discover the server in Meteor on the same network.

Example docs: Enabling DLNA Media Server (QTS).

ASUSTOR
  1. In App Central, install a DLNA/UPnP media server app (for example MiniDLNA or UPnP Media Server).
  2. Open the app and set the sharing folder(s) that contain your movies.
  3. Discover the server in Meteor on the same network.

Vendor overview: ASUSTOR — home media center / MiniDLNA.

Other NAS or media PC

Look for settings named Media Server, DLNA, UPnP AV, or DMA.

  • Enable the service and point it at your movie folders.
  • Use the home / private network profile — guest Wi‑Fi with client isolation often blocks discovery.
  • Check the vendor’s DLNA help for folder and device-access options.

Basic troubleshooting

  • Same Wi‑Fi as the PC/NAS (not guest / isolated Wi‑Fi).
  • Media server actually enabled and sharing a video folder.
  • PC/NAS firewall allowing local media sharing.
  • VPN apps on the phone can hide local devices — try without VPN.

More checks: Help — discovery. Prefer sidecar subtitles or a clearer folder tree? Try SMB or WebDAV.
