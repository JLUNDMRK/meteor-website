Set up SMB

SMB is the familiar “shared folder” protocol used by Windows and most NAS devices. You get direct folder access (good for sidecar subtitles and extras). A username and password are normally required.

← Media access DLNA WebDAV
Use SMB on your home network (or a VPN into home). Do not expose SMB ports directly to the public Internet. For watching away from home without VPN, prefer Download in Meteor or carefully set up Remote WebDAV.

In Meteor

  1. Stay on the same network as the share (or connect via your home VPN).
  2. Add a library via SMB discovery or by entering the host / IP, share name, and credentials.
  3. Browse to the movie folder and start indexing.

Meteor only needs read permission on the movie folders.

Enable file sharing

Windows PC
  1. Right‑click the movie folder → Properties → Sharing → share it with a user who may read the files.
  2. Confirm the network is set to Private, and that password-protected sharing matches how you plan to sign in.
  3. Allow File and Printer Sharing through Windows Firewall on private networks if prompted.
  4. In Meteor, find the PC or enter its local IP address, then select the share and folder.

Microsoft help: share files over a network in Windows (search “file sharing” for your version).

Synology
  1. Control Panel → File Services → enable SMB.
  2. Create or select a shared folder for movies; grant your user at least read permission.
  3. In Meteor: discover SMB or enter the NAS hostname / IP, then open the share.

Vendor docs: Synology Knowledge Center (File Services / SMB for your DSM version).

QNAP
  1. Enable Microsoft Networking / SMB in Control Panel (often under Network & File Services / Win/Mac/NFS).
  2. Share the movie folder and assign a user with read access.
  3. Connect from Meteor with the NAS IP or hostname and that user.

See your QTS / QuTS hero help for “Microsoft Networking” or “SMB”. QNAP documentation.

ASUSTOR
  1. In ADM: Services → SMB → enable SMB.
  2. Ensure Access Control grants your user rights to the movie shared folder.
  3. Connect from Meteor with the NAS address and credentials.

Vendor help: ASUSTOR SMB online help.

Other NAS

Look for File Sharing, SMB, CIFS, or Windows file service.

  • Enable SMB and share the movie folder.
  • Create a user with read access (avoid using your admin account day to day if you can).
  • Connect from Meteor using the device’s local IP or hostname.

Basic troubleshooting

  • Wrong username/password or the user lacks permission on that share.
  • SMB disabled, or only older/newer SMB versions allowed than your NAS expects.
  • Firewall or guest Wi‑Fi blocking access between devices.
  • Typing a public hostname by mistake — on the home LAN, use the local IP or local hostname.
