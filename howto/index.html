Set up media access

Meteor reads movies from a PC or NAS on your network. Pick how your device reaches those files — then index them in the app. No Meteor server or Meteor account is required.

Compare DLNA, SMB, and WebDAV

Not sure which one to choose? Start with DLNA — it is usually the easiest way to get a first library working on a home network.

DLNA SMB WebDAV
Best for Easy home setup Existing network shares / direct folders Flexible access, including secure remote later
Setup Easy Easy–moderate Easy at home; more advanced over the Internet
Username / password Usually no Yes Yes
Folder structure Depends on the media server Full folder access Full folder access
Sidecar subtitles Not reliably available Yes Yes
Remote access No Do not expose directly to the Internet Possible with careful HTTPS setup
Meteor Download Yes Yes Yes

DLNA is the recommended starting point for most people. Many PCs and NAS devices can share movies with a simple “media server” setting, often without a password. What you see (folders, extras, sidecar .srt files) depends on the server — Meteor can only use what that server exposes.

SMB is a good fit if you already have shared folders, or you want a predictable file layout (helpful for sidecar subtitles and extras). Stay on your home network — do not open SMB to the public Internet.

WebDAV also gives direct folder access. At home it is similar in effort to SMB. Using WebDAV from outside your house is a separate, more advanced path — see Remote WebDAV only after local WebDAV already works.

Setup guides

  • DLNA Windows PC or NAS media server — best first try.
  • SMB Network shares and direct folder access.
  • WebDAV Local setup first; remote access is optional and advanced.

Watch away from home with Download

You do not need remote networking just to watch on the go

A simple workflow: connect at home with DLNA or SMB → use Download in Meteor for titles you want offline → play them later without your NAS or home Wi‑Fi.

Meteor indexes your library on the device and can download individual media files for offline playback. That is usually easier — and safer — than opening your home network to the Internet.

Advanced: remote WebDAV

Only needed if you want live streaming from home while you are away, without downloading first. Start with working local WebDAV, then follow Remote WebDAV (HTTPS, hostname/DDNS, port forwarding, and common networking checks).
