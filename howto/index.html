How to connect your movies

Short guide: which protocol to pick, then rough setup for a Synology NAS or a Windows PC. This is not a deep networking manual — just what usually matters.

Contents

  2. Example: Synology
  3. Example: Windows PC

When to choose what

Meteor only reads your movie collection. You pick how the phone/TV reaches those files. All three options work on a home LAN; they differ in simplicity and features.

DLNA — easiest first try

  • Usually no username/password in Meteor.
  • Many NAS boxes and some PC apps expose a “media server” with one toggle.
  • Good for a quick “does my library show up?” test.
  • No sidecar subtitles (external .srt next to the movie) over DLNA.
  • Often slower to browse/index large libraries than SMB/WebDAV.
  • Casting to other living-room devices is often simpler in the DLNA world (future / device-dependent).

Pick DLNA if you want the simplest start on the same Wi‑Fi.

WebDAV — flexible, including away from home

  • Needs login (user/password) and a correct URL/port.
  • Supports sidecar subtitles when files sit next to the movie.
  • Solid for larger libraries when the share is set up cleanly.
  • If you expose WebDAV safely to the internet (HTTPS, strong password, or VPN), Meteor can stream on mobile data outside the home — SMB typically cannot without a VPN.

Pick WebDAV if you want subtitles and/or watching away from home without a full VPN.

SMB — familiar LAN shares

  • Same “shared folder” idea Windows and most NAS use on the local network.
  • Setup effort is similar to WebDAV (host, share name, credentials).
  • Supports sidecar subtitles.
  • Designed for the local network. Reaching SMB from outside usually means a VPN into your home — not opening SMB ports to the open internet.

Pick SMB if you already share folders that way and stay on home Wi‑Fi (or VPN).

Rough rule: try DLNA to verify discovery → use WebDAV or SMB for everyday libraries with subtitles → use WebDAV (or VPN + SMB) if you need access away from home.

Example: Synology

Exact menu names vary by DSM version; look for the same ideas.

DLNA on Synology

  1. Install / open Media Server (or equivalent) in Package Center.
  2. Enable DLNA / UPnP media sharing and point it at the folders that contain movies.
  3. Phone/TV on the same Wi‑Fi as the NAS → in Meteor use Find DLNA.

WebDAV on Synology

  1. Enable WebDAV Server (Package Center / File Services).
  2. Note HTTP/HTTPS ports (common examples: 5005 / 5006 — check your DSM).
  3. Create a user that can read the movie folders (Meteor does not need write access).
  4. In Meteor: Add WebDAV → host = NAS IP or hostname, port if needed, user/password, path to the movie folder.

SMB on Synology

  1. Control Panel → File Services → enable SMB.
  2. Share the movie folder; grant the user read permission.
  3. In Meteor: Find SMB or enter the NAS host, then pick the share and folder.

Example: Windows PC

Use a PC that stays on (or wakes) when you want to watch. Firewall prompts may appear the first time.

DLNA on Windows

  1. Use Windows Media Player / “Media streaming” options, or a lightweight DLNA server app that shares a movie folder.
  2. Allow the app through Windows Firewall on private networks.
  3. Same Wi‑Fi as the phone/TV → Meteor Find DLNA.

SMB on Windows

  1. Right‑click the movie folder → Properties → Sharing → share it.
  2. Use a Windows user with permission to read that share.
  3. In Meteor: Find SMB or enter the PC’s IP, then select the share.

WebDAV on Windows

  1. Windows does not ship a simple “movie WebDAV” toggle. Typical options: enable IIS + WebDAV features, or run a small WebDAV server that points at your movie folder.
  2. Prefer HTTPS if you ever expose it beyond the LAN.
  3. In Meteor: Add WebDAV with the PC’s address, port, credentials, and folder path.

Watching away from home

On home Wi‑Fi, discovery and LAN IPs are enough. Outside the house you need a path from the phone to your server — Meteor does not create that path for you.

What is usually required

  • A reachable address — public IP or a hostname (DynDNS / your NAS vendor’s QuickConnect-style name / your domain).
  • Router port forwarding (or UPnP) from the internet to the NAS/PC service port — or a VPN into your home network (often safer).
  • HTTPS for WebDAV on the open internet, plus a strong unique password.
  • Do not expose SMB (Windows file sharing) directly to the internet.
  • Mobile carriers and CGNAT can block inbound connections; a VPN or vendor relay may still be needed.

Practical combo: VPN into home + SMB/WebDAV on the LAN, or HTTPS WebDAV with careful router/NAS setup. Exact clicks differ per router — check your model’s “port forwarding” / “VPN server” pages.
