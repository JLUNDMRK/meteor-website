Set up WebDAV

WebDAV gives direct folder access (similar to SMB) using a URL, port, and login. This page is for home network setup. Opening WebDAV to the Internet is harder — cover that only in Remote WebDAV after local access works.

← Media access DLNA SMB Remote WebDAV

Prefer watching away from home without remote setup?

At home, connect with WebDAV (or DLNA/SMB), then use Download in Meteor for offline playback. See Download as an alternative.

In Meteor

  1. On the same network as the server, add a WebDAV location.
  2. Enter the host or IP, HTTP/HTTPS port if needed, username/password, and path to the movie folder.
  3. Browse and select the folder to index.

Meteor only needs read access.

Enable WebDAV locally

Synology
  1. Package Center → install WebDAV Server.
  2. Open WebDAV Server and enable HTTP and/or HTTPS. Note the ports (common defaults: HTTP 5005, HTTPS 5006 — confirm in your DSM).
  3. Control Panel → grant the user permission to use WebDAV Server, and read rights on the movie shared folder.
  4. In Meteor, use the NAS local IP (for example https://192.168.x.x:5006) while testing at home.

Official guide: Access files on Synology NAS with WebDAV.

Synology QuickConnect is not a WebDAV address. For WebDAV, use a local IP, a DDNS/hostname you configure, or another direct URL — see Synology’s WebDAV connection notes and the Remote WebDAV guide.

QNAP
  1. Control Panel → Applications → Web Server (enable if required).
  2. Open the WebDAV tab and enable WebDAV.
  3. Note the HTTP/HTTPS ports shown in the UI.
  4. Ensure your user can read the movie folders; connect from Meteor with the NAS local IP.

See QNAP documentation for Web Server / WebDAV on your QTS version.

ASUSTOR
  1. ADM → Services → WebDAV.
  2. Enable WebDAV and/or secured WebDAV (SSL). Note the ports (HTTPS often defaults around 9802 on ASUSTOR — confirm in ADM).
  3. Connect from Meteor using the NAS local IP and credentials.

Vendor guide: ASUSTOR — WebDAV.

Windows PC

Windows does not include a simple “share this movie folder as WebDAV” toggle for home users. Typical options are IIS + WebDAV features, or a small third-party WebDAV server pointed at your movie folder.

  • For a first library on Windows, DLNA or SMB is usually easier.
  • If you do run WebDAV, prefer HTTPS before any exposure beyond the LAN.
Other NAS

Look for WebDAV under file services, web server, or applications.

  • Enable the service and note HTTP vs HTTPS ports.
  • Create a user with read access to movie folders.
  • Test from Meteor with the device’s local IP first.

Basic troubleshooting (local)

  • Wrong port or http vs https.
  • User not allowed to use WebDAV, or no read permission on the folder.
  • Self-signed HTTPS certificates may need trust / acceptance depending on the client.
  • Service enabled but path incorrect — try the shared-folder root first.

Local works but outside does not? That belongs in Remote WebDAV and Help — remote access — not here.
