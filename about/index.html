About Meteor

Independent movie-library application for Android phones, tablets, and Android TV.

Why Meteor?

I built Meteor because I wanted a simple way to browse my own movie collection without unnecessary complexity.

Modern streaming services make discovering movies effortless. I wanted the same experience for media I already own.

Meteor is an independent project created and maintained by a single developer.

What I found was that VLC is excellent at playing almost any file, and a metadata resolver service such as the TMDB or OMDb API can identify most movies — but I still missed a way to present my library nicely without setting up complicated server-driven solutions.

There are many powerful options for tech enthusiasts. The simple path I wanted was: turn on DLNA (or point at a share), install the app, and go.

The goal is that anyone with a movie collection on a NAS or PC should be able — without advanced computer skills — to browse that collection with a good experience. Stream at home from your network; use Download in Meteor for offline playback when you travel; use remote WebDAV only if you want that advanced option.

Install. Index. Enjoy.

Playback

Meteor uses your device’s media capabilities. Hardware-supported decoding is used when the platform provides it.

Some files may not play if the device cannot decode them. I recommend installing the excellent VLC app as a fallback — it can play almost anything, and Meteor can open it for titles the built-in player cannot handle.

VLC already solves broad format support so well that there is little reason for Meteor to ship its own codec package. What Meteor adds is searching and presenting your collection.

Your media & metadata

Meteor provides no movie files, images, or metadata of its own. Library media and related data come from your servers and shares, and from a metadata resolver service (TMDB or OMDb API) and Wikidata / Wikimedia-related sources as configured. You are responsible for having the rights to use that data. Meteor cannot determine or verify those rights.

Where age ratings appear in metadata, Meteor only displays what your library or those sources provide and cannot be held responsible if a rating is incorrect.

Meteor uses a metadata resolver service such as the TMDB or OMDb API for accurate titles and metadata. Supporting those providers — for example by contributing or using your own API key where offered — helps keep identification working well. See Metadata & Attribution.

Open source & licenses

Meteor may include or link open-source components used for the app itself (for example networking and UI libraries). Attribution also appears in the app under Settings → Other / About.

VLC is a separate application from VideoLAN. Meteor can open it as a recommended fallback when needed. Project site: videolan.org.

Meteor is developed independently and is not affiliated with Netflix, TMDB, OMDb, IMDb, Wikipedia / Wikimedia, any device manufacturer, or any media server vendor.

Pricing

Meteor is free to use in the current release.

My goal is to always keep a free base version of the app. Extended features may cost something in the future to help support development and running costs. If that happens, users will be informed in the app before anything is charged.

Features, metadata access and supported services may change as the project evolves.
