About Meteor

Independent movie-library application for Android, iPhone, and Apple TV.

Why Meteor?

I built Meteor because I wanted a simple way to browse my own movie collection without unnecessary complexity.

Modern streaming services make discovering movies effortless. I wanted the same experience for media I already own.

Meteor is an independent project created and maintained by a single developer.

There are many excellent media setups for tech enthusiasts — powerful, flexible stacks, often with accounts, remote services, and more to configure and maintain. I am technical enough to run them, but I got tired of the overhead — and I do not want to pay for that kind of solution just to watch my own movies at home.

What I missed was the simple path: turn on DLNA (or point at a share), install the app, and go — without standing up complicated server-driven setups or unnecessary configuration.

Meteor focuses primarily on indexing, movie identification, metadata and library navigation. Playback uses the device’s built-in media player.

Install. Index. Enjoy.

Codecs & playback

This version of Meteor plays with your device’s built-in media player and the codecs that already come with the operating system. It does not embed extra codec engines such as FFmpeg or VLCKit.

Some files may not play if the device cannot decode them. When needed, Meteor can open the separate VLC app if you have installed it.

Your media & metadata

Meteor provides no movie files, images, or metadata of its own. You accept responsibility for OMDb API data (and other metadata providers) that you use, and for any movies or files you copy or download locally for use with the app.

Open source & licenses

Meteor may include or link open-source components used for the app itself (for example networking and UI libraries). Attribution also appears in the app under Settings → Other / About.

VLC is a separate application from VideoLAN. Meteor may open it when you choose to; Meteor does not ship or embed VLC / VLCKit in this version. Project site: videolan.org.

Independence

Meteor is developed independently and is not affiliated with Netflix, TMDb, OMDb, IMDb, Wikipedia, any device manufacturer, or any media server vendor.

Support the Project

Base functions are free to use. Some features are reserved for active supporters — a low tip-jar contribution that helps fund development and maintenance.

My hope is that users who like the app will contribute so I can keep improving it. The goal is to keep Meteor affordable and accessible. If ongoing costs increase, the funding model may need to change to keep the project sustainable.

You can cancel a Supporter subscription at any time. Features and pricing may change as the project evolves; there is no guarantee which capabilities stay free forever.

Features, pricing, metadata access and supported services may change as the project evolves. No permanent availability of any particular third-party service is promised.
